# 당구 메이트 매칭 서비스, 너쫌친당

### 원하는 때에, 손쉽게 당구 상대를 찾을 수 있는 온라인 플랫폼

<br/>

## 프로젝트 목표
 1. 오프라인에서 당구 게임을 마련하는 번거로움을 줄이고, 실시간 채팅을 활용한 간편하고 효율적인 매칭 시스템을 제공한다.
 2. 매칭이 확정되면, 시스템이 자동으로 게임을 생성하고 결과를 기록하여 전반적인 사용자 경험을 향상시킨다.
 3. 사용자뿐만 아니라 관리자도 편한 사이트, 모두를 만족시키는 플랫폼을 만든다.
<br/>

## 팀 목표

### 🙋‍♀️ 실사용자 유치
&nbsp; MVP를 개발한 후, 실제 사용자를 유치하고 피드백을 받으며 디벨롭 한다.

### 🙌🏻 소통능력 함양
&nbsp; 팀원 간 진행상황 공유 및 적극적 소통을 바탕으로 프로젝트를 이어나갈 수 있도록 한다.

<br/>
